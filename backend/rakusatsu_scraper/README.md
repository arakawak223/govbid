# 落札企業スクレイパー（結果ページ対応版）

まとめxlsxの案件について、公募ページに加え**結果ページ**から落札企業を抽出する。

## 構成
- `extract.py` … 落札企業抽出コア。勝者ラベル限定・前株/後株・（株）等略記正規化(prep_text)・
  「次点/参加業者」除外・ラベル直後アンカー優先・全文探索。単体で堅牢。
- `discover.py` … 結果ページ発見。検索(DDG等)で「案件名+結果」から結果URLを特定し、
  案件タイトルの掲載を確認した上で抽出（誤検出防止）。※検索バックエンドが到達可能な環境が必要。
- `scrape_v3.py` … 主スクレイパー（Sheet1のURL取得→本文/リンク/PDFから抽出）。
- `build_excel2.py` … スクレイピング結果＋PR照合分を統合し、0616差分（新規公表）Excelを生成。

## 既知の制約（当環境）
- 多くの自治体サイトはデータセンターIP/UAに404を返す→生存率が実際より低く出る。
- 公開検索エンジン(DDG/Bing)はレート制限/ボット判定で不安定。ハーネスWebSearchは有効。
- 2026年の新しい公募は結果未公表が多い。
